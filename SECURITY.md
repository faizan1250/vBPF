# Security Policy

Threat model (assets, actors, trust boundaries, STRIDE table, residual risks): [`docs/threat-model.md`](docs/threat-model.md).

Hardening details: [`docs/security.md`](docs/security.md).

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.3.x   | Yes       |
| < 0.3   | No        |

Only the latest minor release line receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report through
[GitHub private vulnerability reporting](https://github.com/faizan1250/vBPF/security/advisories/new)
(the repository "Security" tab, "Report a vulnerability").
We aim to acknowledge reports within 3 business days.
